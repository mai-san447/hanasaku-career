## ワーク2: 行動パターンを見つける

ワーク1のエピソードを見て、共通する「あなたの行動パターン」を見つけましょう。

### チェックリスト（当てはまるものに○）

**人との関わり方**
- [ ] 困っている人にすぐ声をかける
- [ ] チームをまとめる役割になりやすい
- [ ] 一人ひとりの話をじっくり聞く
- [ ] 新しい人とすぐ打ち解ける
- [ ] 裏方として支えるのが好き

**物事への取り組み方**
- [ ] 計画を立ててから動く
- [ ] まずやってみてから考える
- [ ] 細かいところまでこだわる
- [ ] 全体を見て優先順位をつける
- [ ] 新しいやり方を考えるのが好き

**困難への向き合い方**
- [ ] 粘り強く続ける
- [ ] 別の方法を探す
- [ ] 人に相談する
- [ ] 冷静に分析する
- [ ] ポジティブに考え直す
