## 自己チェック

### 構成・論理

- [ ] **結論が最初に書かれている**（「私の強みは〜です」「志望理由は〜です」）
- [ ] **エピソードが具体的**（いつ・どこで・何をしたかが書かれている）
- [ ] **数字が入っている**（「3か月で」「20人のチームで」「売上1.5倍」など）
- [ ] **「なぜ？」に答えている**（動機・理由が明確）
- [ ] **企業への貢献が書かれている**（自分の話だけで終わっていない）

### 表現・読みやすさ

- [ ] **一文が短い**（60文字以内を目安に）
- [ ] **「〜と思います」が多すぎない**（「〜です」「〜しました」と言い切る）
- [ ] **同じ言葉の繰り返しがない**
- [ ] **誤字・脱字がない**
- [ ] **文字数制限を守っている**（±10%以内が理想）

### 内容の深さ

- [ ] **「あなたらしさ」が伝わる**（他の人でも書ける内容になっていない）
- [ ] **課題→行動→結果の流れがある**
- [ ] **失敗や困難にも触れている**（完璧な話より成長が見える話）
- [ ] **この企業でなければいけない理由がある**（他社にも使い回せる内容になっていない）
