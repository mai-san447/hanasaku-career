## 優先順位

| 優先度 | 項目 | 理由 |
|---|---|---|
| **最優先** | Stripe本人確認 | 決済ができないとサービス開始不可 |
| **最優先** | 特商法メールアドレス記入 | 法的要件 |
| **高** | OG画像作成 | SNS共有時のプレビューに影響大 |
| **高** | LINEリッチメニュー | 友だち追加後の導線 |
| **高** | 友人の子供さん無料面談 | テストケースとして最重要 |
| **中** | Instagram開設 | 集客チャネル |
| **中** | GA4設置 | 効果測定のため早めに |
| **要確認** | 持続化補助金 | 締切4/30、早めの準備が必要 |
