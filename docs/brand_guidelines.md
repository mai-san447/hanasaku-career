## 1. ブランド概要

| 項目 | 内容 |
|---|---|
| サービス名 | ハナサク |
| 英語表記 | HANASAKU |
| タグライン | 福井の女の子が、自分の言葉で未来を語れるようになる就活伴走サービス |
| 運営者名義 | 西川 舞衣子（EMKO） |

### 名称の由来

「花が咲く」＝ 自分らしいキャリアが花開く、という意味。当初は「ふくむすめキャリア」（福井特化）だったが、全国展開も視野に入れて変更。

## 4. ロゴ

### 構成要素

- **花モチーフ**: 5枚の花びら（#C06070, #E8A0A8, #D4808E の交互）+ 中央の白い円
- **ロゴタイプ**: 「ハナサク」（Zen Maru Gothic, 700）
- **サブテキスト**: 「就活伴走コーチング」（Zen Maru Gothic）

### ロゴファイル

| ファイル | 用途 |
|---|---|
| `logo.html` | マスターデータ（HTML/CSS製） |
| ※ PNG書き出し要 | SNSアイコン、OG画像等 |

### 使用ルール

- ロゴの花びらの色・配置を変更しない
- ロゴの周囲にはロゴ高さの25%以上の余白を確保する
- 背景は白 or Primary Light を推奨。暗い背景では使用しない
- ロゴを傾けたり、縦横比を変えたりしない

### 推奨書き出しサイズ

| 用途 | サイズ | 形式 |
|---|---|---|
| LINEアイコン | 640×640 px | PNG |
| OG画像 | 1200×630 px | PNG/JPG |
| favicon | 32×32 / 180×180 px | PNG |
| SNSアイコン | 400×400 px | PNG |

## 5. トーン＆ボイス

### ブランドパーソナリティ

| キーワード | 説明 |
|---|---|
| あたたかい | 就活の不安に寄り添う、家族のような安心感 |
| 誠実 | 無理な勧誘はしない、嘘をつかない、できないことはできないと言う |
| プロフェッショナル | 社外メンター経験に基づく、根拠のあるアドバイス |
| 等身大 | 「すごい人」ではなく「少し先を行く先輩」としてのポジション |

### 文体ルール

- **です/ます調**を基本とする（硬すぎず、くだけすぎない）
- 専門用語は使わないか、使う場合は必ず補足する
- 「〜してあげる」「〜させる」は使わない（対等な関係性を重視）
- 学生には「あなた」、親には「親御さん」「お母さん/お父さん」と呼びかける
- 命令形は使わない（「〜してください」ではなく「〜してみませんか？」）

### 使ってよい表現

- 「伴走」「一緒に」「寄り添う」「あなたの言葉で」
- 「お気軽に」「まずは無料で」「無理な勧誘はしません」
- 「花が咲く」「自分らしい」

### 使わない表現

- 「内定保証」「必ず受かる」「成功する」（過度な約束）
- 「就活弱者」「ダメな面接」（否定的なラベリング）
- 「コンサル」「戦略」（ビジネス色が強すぎる）
- 「ママ」（親御さん向け文脈では「お母さん」を使う）

## 7. 写真・ビジュアル方針

### 写真のトーン

- 自然光、明るく暖かみのある色調
- 人物写真は笑顔・リラックスした表情
- スーツ姿よりカジュアル寄り（ただしきちんと感は残す）

### NG例

- ストックフォト感の強い不自然なポーズ
- 暗い・冷たい色調
- 男性中心のビジネスシーン

### イラスト・アイコン

- 花・植物モチーフを積極的に使用
- 線画 or フラットデザイン（Primary カラー系統）
- 角丸・丸みのあるデザインで統一
